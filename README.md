# Fraudette AI - (A fraud detection system)

**Built for:** Paylabs Mini Hackathon 2026

Quick start

### Prerequisites
- Node.js 16+ 
- npm or yarn
- Alibaba Cloud API Key

```bash
git clone https://github.com/SoniaRY-15/alibaba-hackathon.git
cd alibaba-hackathon/backend
npm init -y
npm install express
npm install --save openai
create .env and get the alibaba API key
npm run dev
# open:  http://localhost:5000/api (for backend)
# use live server for the frontend
```
