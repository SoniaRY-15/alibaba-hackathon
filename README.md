# Fraudette AI - A fraud detection system made for Alibaba x Paylabs hackathon



Quick start

```bash
git clone https://github.com/SoniaRY-15/alibaba-hackathon.git
cd alibaba-hackathon/backend
npm init -y
npm install express
npm install --save openai
npm run dev
# open:
# http://localhost:5000/api
```
